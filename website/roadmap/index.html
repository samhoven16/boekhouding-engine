📅 Update-aanpak

Boekhoudbaar wordt actief onderhouden door één persoon. Bug-fixes pak ik zo snel mogelijk op (meestal binnen een paar dagen, soms langer bij vakantie of ziekte). Kleine verbeteringen en grotere features rollen continu uit. Klanten krijgen automatisch alle updates — geen hand­matige acties. Wijzigingen komen mee bij de eerstvolgende sheet-open via het migratie­framework.

✅ Klaar In productie · 2026

✓
Volledige boekhouding Facturen, kosten, bonnetjes, declaraties, bankboek, journaalposten, BTW-aangifte, jaarrekening, dashboard.
✓
Mollie iDEAL betaal-link op factuur Klant scant of klikt — direct betaald. Werkt via Mollie (geen abonnement, alleen kleine transactiekosten).
✓
AI bonnen-scan via Gemini Vision Foto van bon → leverancier, datum, bedrag, BTW automatisch ingevuld.
✓
KvK auto-fill Bedrijfsnaam, adres, BTW-nummer worden auto-ingevuld op basis van KvK-nummer.
✓
Persoonlijke fiscale signalering Heffingskorting, lijfrente-jaarruimte, KIA/MIA/EIA, MKB-vrijstelling. Met bronvermelding.
✓
Bank-CSV import + auto-match ING, Bunq, Rabo, ABN — alle Nederlandse banken. Automatische factuurmatching.
✓
Accountantspakket export PDF + XLSX + JSONL voor accountant. Werkt met Snelstart, Exact, Twinfield.
✓
iCal feed BTW-deadlines Abonneer in Google/Apple/Outlook agenda. Auto-herinneringen 7 + 14 dagen vooraf.
✓
Mobile responsive dialogs Werkt op iPad, telefoon, Mac, Windows. Touch-friendly tap-targets.
✓
Audit-trail 7 jaar (AWR-compliant) Volledige export per jaar, traceerbaar voor accountant of curator.
