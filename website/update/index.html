Updates

Boekhoudbaar updaten

Hoe je een nieuwere versie krijgt — eerlijk uitgelegd, inclusief wat nog niet automatisch werkt.

De korte versie
Op dit moment is updaten een handmatige stap (5–10 minuten). Voor kritieke fiscale fixes krijg je een melding bij het openen van je spreadsheet. Volledig automatische updates volgen in een latere versie — die staan bewust nog niet aan omdat een half-werkende auto-update zelf een groter risico is dan handmatige updates.

Wanneer moet ik updaten?

Drie scenario's, in volgorde van urgentie:

  • Kritieke update (rode modal bij openen sheet) — bevat een BTW-correctie, jaarafsluiting-fix of compliance-aanpassing. Doe dit binnen een week, en in elk geval vóór je volgende BTW-aangifte.
  • Nieuwe versie beschikbaar (gele toast onderaan scherm) — niet-urgent. Update wanneer het uitkomt. Bevat meestal nieuwe functies of UX-verbeteringen.
  • Geen melding — je bent up-to-date. Je kunt het altijd zelf checken via menu Boekhoudbaar → Licentie & Updates → Hoe update ik?

Procedure (handmatig, tier 1)

Stuur Sam een mail. Tot we tier 2 (zelf-update vanuit de sheet) aanzetten, doet hij het persoonlijk voor je — meestal binnen 24 uur.

  1. Open menu Boekhoudbaar → Licentie & Updates → Licentie-informatie en noteer je versie + spreadsheet-ID.
  2. Mail naar update@boekhoudbaar.nl met: huidige versie, gewenste versie (of "nieuwste"), je spreadsheet-ID. Bij kritieke updates ook de melding-tekst die je zag.
  3. Wacht op antwoord met stappenplan — bevat een unieke link met de nieuwe code-files en exacte plak-instructies, afgestemd op jouw versie-sprong. Stappen zijn altijd reversible (je administratie blijft intact).
  4. Volg het stappenplan — meestal: Apps Script editor openen, een aantal bestanden vervangen, één keer setup() uitvoeren. Sam blijft beschikbaar terwijl je het doet.
  5. Verifieer — open de sheet opnieuw, check via Boekhoudbaar → Licentie & Updates → Hoe update ik? dat de versie nu matched.
Lees dit voordat je begint: verander niets in de Apps Script editor zonder duidelijke instructie. Je administratie staat in jouw eigen Google Drive — die kan Sam niet zien en niet herstellen als de code stuk gaat. Daarom is een mail-bevestiging vooraf de veiligste route.

Wat als ik niets doe?

Bij een normale update: niets ergs. Je krijgt elke 7 dagen één toast tot je update, daarna stopt 'ie. Je administratie blijft werken op je huidige versie.

Bij een kritieke update: je administratie blijft werken, maar berekeningen kunnen onjuist zijn. Een BTW-aangifte op een verouderde versie kan bijvoorbeeld een rubriek (r1a/r1b/r1e) onjuist berekenen of een tariefgrens missen die de Belastingdienst wel toepast. Verantwoordelijkheid voor de juistheid van de aangifte blijft bij de ondernemer (AWR art. 8) — update tijdig. De modal blijft elke 24u terugkomen tot je update.

Tier 2 — automatische update (komt later)

Een ingebouwd "Update nu"-menu-item dat de nieuwste code direct in jouw sheet zet, via de Apps Script API met SHA-256-handtekening-verificatie. Werkt voor minor updates; major updates blijven handmatig vanwege migraties.

Reden voor wachten: code-injection-risico. Tier 2 vereist dat jouw script eigen broncode mag aanpassen — dat is een gevoelige scope. We zetten dit pas aan als (a) de licence-server-handtekening geverifieerd, (b) een rollback-pad bewezen, en (c) een gefaalde update altijd kan terugkeren naar de vorige versie. Komt na go-live in een gefocuste release.
