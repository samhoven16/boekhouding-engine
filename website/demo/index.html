Wat kun je in 5 minuten testen?

1. Klik door alle tabbladen

Onderaan zie je tab-knoppen: Dashboard, Instellingen, Verkoopfacturen, Inkoopfacturen, Banktransacties, Relaties, BTW Aangifte, Grootboekschema, Balans, W&V Rekening. Bekijk de structuur en kolommen.

2. Maak een eigen kopie + klik op menu

  1. Klik Maak een kopie
  2. In de kopie zie je Boekhouding-menu boven (naast Hulp). Daar zit alles: Nieuwe boeking, BTW-aangifte, Dashboard refresh, etc.
  3. Klik bv. Boekhouding → Nieuwe boeking → factuur-dialog opent
  4. Probeer een fictieve factuur in te voeren — zie totaal automatisch berekenen

3. Bekijk een bestaande factuur

Op Verkoopfacturen-tab: scroll door rijen. Klik op een PDF-link in de kolom rechts → factuur-PDF opent. Zo ziet de uitgave naar jouw klant er straks uit.

4. Test BTW-aangifte

Op BTW Aangifte-tab: zie hoe alle facturen + kosten van een kwartaal worden samengevat in officiële Belastingdienst-rubrieken (1a t/m 5d). Direct overneembaar in mijn.belastingdienst.nl.
